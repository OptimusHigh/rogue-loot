# 📜 План Расширения Лута Roguelike Dungeons (GanjaCraft Fabric 26.3)

> **Статус:** Концепт и дорожная карта расширения  
> **Версия Minecraft:** `26.3` (Fabric Loader 0.19.5, DataComponents, Pack Format 48)  
> **Ключевой движок лута:** `roguelike-dungeons` (`"roguelike_loot": false`) + `slashloot` (индивидуальный лут контейнеров)

---

## 🎯 1. Цели и Философия Редизайна

1. **Разрушение монотонности ванильного рогалика:**
   Оригинальный генератор мода Roguelike Dungeons заполнял сундуки тоннами мусора (стрелы по 1 шт., семена пшеницы, булыжник, гнилая плоть).
   Новая система превращает каждый сундук в осмысленную награду, создавая азарт и прогрессию с 1 по 5 этаж.

2. **Строгое зонирование прогрессии (Floor Tiers):**
   * **Этаж 0 (Starter / Башня):** Набор выживания (факелы, хлеб, мешок `bundle`, каменные инструменты, кожанка).
   * **Этажи 1–3 (Tier 1):** Железный век, медь, уголь, кольчуга, начальные шаблоны брони, археология, декор туфа/меди. **Никаких алмазов!**
   * **Этажи 4–5 (Tier 2 / Abyss):** Алмазный тир, редчайший незерит, эндгейм-компоненты 26.3, шаблоны отделки, запечатанные реликвии.

3. **Синхронизация с экосистемой сервера GanjaCraft:**
   * **Кузница (`/forge`):** Высокотирные предметы имеют ценность для починки и перековки.
   * **Система Тримов (`TrimLoreManager`):** 18 шаблонов и 11 материалов дают активные RPG-пассивки (хп, скорость, дальность стройки/атаки).
   * **Реликвии (`BountyRelicManager`):** Возможность выбить ультраредкие запечатанные реликвии боссов в самых глубоких сундуках.
   * **Жильная добыча (`VeinMiner`):** Редкие книги зачарования жильной добычи.

## 🧩 3. Анализ и Синергия с Модами Сервера

### 1. `Towns and Towers` (`kaisyn`)
* **Что есть в моде:** Богатая археология (`forest_ruins_rare.json`), сундуки аванпостов (`outpost/common/armory.json`), кузницы деревень (`village_classic_blacksmith.json`).
* **Как используем:** 
  - Редкие глиняные черепки (`burn`, `danger`, `friend`, `heart`, `heartbreak`, `howl`, `sheaf`) добавляются в сундуки археологии и библиотек 1-3 этажей.
  - Оружие разбойников и наемников обогащает `weapon1` (арбалеты с пронзанием, железные секиры).

### 2. `Moogs Voyager Structures` (`mvs`)
* **Что есть в моде:** Морские башни (`ocean_tower/treasure.json`), соборы (`cathedral_base.json`), алхимия (`houses_brewing.json`).
* **Как используем:**
  - Морские сокровища (Раковины наутилуса, Сердце моря, Трезубцы) гармонично вписаны в `music.json` и `weapon2.json`.
  - Зельеварение `houses_brewing` послужило ориентиром для балансировки взрывных и удлиненных зелий в `brewing.json`.

### 3. `Formations Overworld & Nether`
* **Что есть в моде:** Замки черного камня (`blackstone_castle.json`), гробницы (`graveyard/tomb.json`), лавовые арены.
* **Как используем:**
  - Атмосферный незерский лут (визер-розы, слезы гаста, зелья огнестойкости, адские грибы) дополняет глубокие этажи 4-5.
  - Кольчужная броня с проклятиями и высокими чарами из склепов перенесена в пул `armor1` и `armor2`.

### 4. `VeinMiner` (`veinminer-fabric` + `veinminer-enchant`)
* **Что есть в моде:** Зачарование `veinminer_enchantment:veinminer`.
* **Как используем:**
  - Зачарованные книги `veinminer_enchantment:veinminer` добавляются в `tool2.json` и `supply2.json` на 4–5 этажах с низким контролируемым весом (1–2).
  - Это создает колоссальный стимул для игроков исследовать глубокие опасные уровни!

### 5. `GanjaCraftCore` (Реликвии и Экономика)
* **Что есть в ядре:** 16 кастомных артефактов боссов (`BountyRelicManager`), система запечатывания (`relic_sealed: true`).
* **Как используем:**
  - В лут-таблицы `tool2.json`, `weapon2.json`, `armor2.json` на 5 этаже подземелья добавляется ультраредкий шанс найти **Запечатанную Реликвию** (например, `sealed_soulcatcher_pickaxe`, `sealed_demolition_mace`, `sealed_executioner_blade`, `sealed_welding_mask`).
  - Формат в 26.3 через DataComponents:
    ```json
    {
      "type": "minecraft:item",
      "name": "minecraft:netherite_pickaxe",
      "weight": 1,
      "functions": [
        {
          "function": "minecraft:set_components",
          "components": {
            "minecraft:custom_data": {
              "bounty_relic": "soulcatcher_pickaxe",
              "relic_id": "soulcatcher_pickaxe",
              "cit_id": "sealed_soulcatcher_pickaxe",
              "relic_sealed": true,
              "CustomModelData": 7701
            },
            "minecraft:custom_name": "{\"text\":\"§6§l✦ Запечатанная Кирка Ловца Душ\",\"italic\":false}"
          }
        }
      ]
    }
    ```
